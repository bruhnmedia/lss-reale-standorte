# BRUHN MEDIA | Reale BOS-Standorte Niedersachsen

**Standortdaten für die BRUHN MEDIA LSS Tools.**

Die Datenbank stellt geografische Standortinformationen zu Feuerwehr, Polizei, Rettungsdienst, Krankenhäusern und Hilfsorganisationen in Niedersachsen bereit. Grundlage sind die frei verfügbaren Daten aus OpenStreetMap, die regelmäßig automatisiert aufbereitet und veröffentlicht werden.

## Standortdaten

[BRUHN MEDIA · Niedersachsen-Datenbank](https://bruhnmedia.github.io/lss-reale-standorte/manifest.json)

Die Standortdaten ergänzen die unabhängigen BRUHN MEDIA-Erweiterungen für Leitstellenspiel.de. Angaben zu Standorten und Organisationen können unvollständig, veraltet oder fehlerhaft sein.
